# Interface Web Êxito

Este diretório contém o frontend Angular 17 da Êxito Multimarcas.

Para requisitos, configuração do banco e execução integrada com a API Spring Boot, consulte o [README principal](../README.md).

Comandos úteis dentro deste diretório:

```powershell
npm ci
npm start
npm run build
npm test -- --watch=false
```
